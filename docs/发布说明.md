### 一、这个 mod 有什么

**1. 特征面板新增「战斗技能」区块**（在武器技能下方）
- 攻击 / 防御 / 敏捷三项，等级 F- 到 S 共 16 档
- 每档：攻击力 +5、防御力 +5、敏捷 +5
- 效果：
  - **攻击力**：每 1 点 → 造成伤害 +1%
  - **防御力**：每 1 点 → 受到伤害 −1%（上限 −90%），疼痛同步降低
  - **敏捷**：直接加进 舞蹈 / 运动 / 游泳 / 足部 的技能判定（缠斗闪避也走这些技能）

**2. 战斗成长**
- 打中敌人 → 攻击 +1
- 被击中 / 被怪物扑袭 → 防御 +1、敏捷 +1
- 敏捷判定成功（缠斗闪避/险闪）→ 敏捷 +10

**3. 战利品**
- 击败**人类** NPC：65% 掉钱（£10~30）、30% 掉物品
- 击败**非人类** NPC：45% 掉它身上带着的东西（避孕套 / 胡椒喷雾 / 赃款）
- 战斗结束界面显示「战利品」面板（逐项列出 + 现金/赃款合计）

**4. 拳击俱乐部（康努达塔斯街新地点）**
- **当陪练挣钱 (0:30)**：攻击 +1、防御 +2、敏捷 +1、意志 +1，疼痛上升，报酬 £20~40
- **拳击训练 (0:20 £20)**：攻击 +2、敏捷 +1、运动 +5 点经验
- 更衣室 (0:01)、浴室和淋浴间 (0:01)；胜场越多对手越硬

**5. 酒吧斗殴（丰收街 Pub）**
- 可和路人约架：赢了拿 £5~15 彩头，**输了会被保镖丢出酒吧**，落在丰收街上
- 对手随胜场变强，连赢后有专属挑衅台词

**6. 战斗动作「反剪双臂」**
- 左手/右手动作列表新增「反剪双臂」：力量（physique）判定
- 成功把对方双臂反剪按住，封住对方用手类动作，按住 2 回合；期间动作变为「继续压制」
- 失败会被反制、吃疼痛；人类和野兽敌人都可用

### 二、安装方法

> 前置：游戏自带 ModLoader（0.5.x 都有）+ **TweeReplacer** 插件

1. 下载 `CombatSkills_v1.12.1.zip`
2. 游戏内 ModLoader → 添加 zip → 选择该文件
3. 刷新页面；打开「特征」面板，最底部显示 `CombatSkills mod v1.12.1` 即安装成功

**卸载**：ModLoader 里移除本 mod 即可，游戏文件零改动、完全恢复原状。

### 五、常见问题

**Q：装了没变化？** 先看特征面板底部版本号；再确认是不是网站加载和 ModLoader 各装了一份（两份会互相覆盖，删掉 ModLoader 里那份）。

**Q：某些场景报 `macro <<xxxicon>> does not exist`？** 通常是别的 mod 引用了 0.5.11.9 里不存在的宏；本 mod 从 v1.11.3 起已为 `askicon` 兜底，若还有别的宏名请按反馈格式发我。

**Q：酒吧里没有斗殴？** 需要 v1.11.1+，旧版请强刷页面（Ctrl+Shift+R）或重装。
