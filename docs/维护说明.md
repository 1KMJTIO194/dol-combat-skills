# 维护说明（给自己看的）

## 本地工作流

- 构建环境：`<game>/Degrees of Lewdity.html`（0.5.11.9）+ `build.ps1` + `CombatSkills/` 源目录 + Node.js
- 构建：`pwsh -File .\build.ps1` → 在**上一级目录**生成 `CombatSkills_v<版本>.zip` 与 `modList.json`
- 仓库只提交**源文件**（`boot.json`、`twee/`、`dist/`、`css`、文档、`build.ps1`）；
  zip 与 `modList.json` 已被 `.gitignore` 忽略

## 发新版本

1. 改 `build.ps1` 里的 `$Version`
2. 同步版本号：
   - `CombatSkills/twee/CombatSkills.tw` 面板页脚的 `CombatSkills mod vX.Y.Z`
   - `CombatSkills/dist/js/installCombatSkillsPatch.js` 的 `CS_VERSION = "X.Y.Z"`
   （构建脚本会校验两处与 `$Version` 一致，不一致直接失败）
3. 跑构建，确认自检全绿
4. 更新 `CHANGELOG.md`
5. 提交并推送：

```powershell
git add -A
git commit -m "vX.Y.Z: <改动摘要>"
git push
```

6. 在 GitHub 建 Release（tag `vX.Y.Z`），把构建出的 zip 作为附件上传

## 仓库结构

```
build.ps1                 构建脚本
CombatSkills/             mod 源（= zip 内容）
  boot.json               ModLoader 清单
  twee/CombatSkills.tw    widget 与新增段落
  dist/…                  JS 补丁（pain 减伤 / currentSkillValue 敏捷接入）
  CombatSkills.css        战利品面板样式
  README.md               详细中文文档
docs/发布说明.md           发布帖草稿（含吧规合规说明）
tools/decode-save.js      存档解压调试工具
CHANGELOG.md              更新日志
```

## 注意

- 补丁锚点必须是**纯代码**：含英文界面文字的锚点会被汉化 mod 改掉，导致补丁静默失效
- TwineScript 只认 `lt / lte / gt / gte / eq / neq`，写 `le / ge / ne` 会在运行时抛错（构建里有校验）
- 发版后如需替换同版本 zip，GitHub Release 需要先删旧资产再上传
